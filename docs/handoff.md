## 3. 已锁定决策（不得重新反复争论）

以下为上一轮讨论中用户明确确认的决策，除非用户主动提出变更，否则视为既定前提：

| 决策 | 结论 |
|---|---|
| 桌面框架 | **Tauri 2**（曾对比 Electron，用户最终选择 Tauri 2） |
| 前端 | Vue 3 + TypeScript + Vite |
| 分发形态 | **便携版（免安装）**，直接运行构建产物；不产出 MSI/NSIS，不做签名与公证 |
| 开机自启 | **不做**；由用户手动启动后长期常驻 |
| 数据与配置目录 | 固定于便携目录内（实现为 data 子目录），**不提供改路径设置项** |
| 数据库 | SQLite 作为唯一 Source of Truth；通过 `tauri-plugin-sql` 访问；**SQL 与数据语义留在 TypeScript**；不使用 ORM |
| 数据库迁移 | 在 Rust 侧声明 migration |
| AI 请求传输 | 自定义 Rust 薄命令（reqwest），只做"发请求、回内容"；**不使用 `tauri-plugin-http`**（原因见 `tech-plan.md` §3.1） |
| Rust / TS 边界 | **「何时」与「系统」归 Rust，「做什么」与「规则」归 TS**（详见 `tech-plan.md` §4.2） |
| AI 总结触发 | **MVP 仅手动生成**；自动触发与补偿整体后移到阶段 4 |
| macOS 条件 | 用户有 Mac，可本地构建调试 |
| 软删除 | 采用（`deleted_at`） |
| 过期判定 | 内容指纹 `source_revision`，读取时比较，不维护"过期标志" |
| 结构化结果存储 | `daily_summary.payload` JSON 列，不拆多表 |
| 搜索 | MVP 用参数化子串匹配（`LIKE`），不引入 FTS5 |
| Markdown / JSON | 单向派生输出，**绝不回读** |
| 密钥存储 | 凭据库绑定机器而非目录，与便携语义冲突，`keyring` 降为备选；阶段 3 在便携目录内加密文件（口令派生密钥）与明文 + 风险提示间定案 |

**不要重新提议**：Electron 迁移、Rust 内 rusqlite 替代方案、AI 自动触发的 MVP 化、ORM 引入、FTS5 提前落地——这些都已在上一轮讨论过并给出了结论或延后安排。

## 4. 需求红线

### 4.1 MVP 必须覆盖

Quick Capture 完整体验（草稿、中文输入、快捷键冲突检测与自定义）；后台常驻体系（托盘/菜单栏、单实例、暂停快捷键）；Entry 记录与浏览（今日、历史日期、编辑、删除、复制）；SQLite 持久化与导出备份；基础搜索；每日 AI 总结（手动）；设置页。

### 4.2 明确不做（任何阶段都不得擅自引入）

被动监听键盘/输入法、读取其他应用输入框、Keylogger、浏览器扩展、OCR、截屏识别、云服务、账号、多用户、实时同步、向量数据库、Embedding、RAG、Agent、知识图谱、自动长期记忆、自动人格分析、实时 AI 对话、每条 Entry 实时分类、重型笔记系统层级结构。

### 4.3 需求冲突修正结论（必须遵守）

| # | 结论 |
|---|---|
| 1 | 不追求"不抢焦点"。**快速记录必然短暂抢占焦点，隐藏后归还焦点给原应用**（macOS non-activating panel 会导致无法输入中文，不可采用） |
| 2 | **Esc = 保留草稿并隐藏**，不提供取消语义 |
| 3 | 自动总结**不做"补跑错过的定时任务"**，改为声明式期望状态 + 对账扫描 |
| 4 | 自动总结目标日期问题随"仅手动"暂缓到阶段 4 |
| 5 | 默认快捷键保留（Win `Ctrl+Shift+Space` / macOS `Cmd+Shift+Space`），但**注册失败必须可见**并提供换键入口 |
| 6 | **日期在写入时固化为独立列**，不在读取时动态推导；不做自动重算 |
| 7 | 暂停 = 注销全局快捷键（阶段 4 起追加暂停自动总结） |
| 8 | Markdown / JSON 单向派生输出 |
| 9 | 草稿 MVP 为全局单一 active draft，表结构预留多草稿扩展位 |
| 10 | 便携版下不做开机自启，改为用户手动启动后长期常驻（代价：忘记启动则当天无记录，已确认接受）；数据与配置固定在便携目录，移除「数据目录」设置项 |

### 7.2 已落入源码的实现与边界

以下是实现现状，不是已验证的运行结论：

- **双窗口**：`index.html` / `capture.html` 分别承载 main 与 capture。main 只提供状态、错误、换键、暂停和退出入口，不包含记录浏览或完整设置页；capture 在数据库初始化后创建为隐藏窗口，草稿载入成功后才确认可输入。
- **原生壳**：已接入托盘、单实例、平台默认全局快捷键与隐藏/退出保存握手。待办动作 ID 保留在 Rust 内存中，事件仅作提示，TS 主动查询并通过 DOM 焦点、可见性与首次输入补充同步。焦点归还目前依赖系统隐藏行为，尚未真机确认。
- **便携路径**：dev 使用项目根目录 `data/`；Windows release 使用 exe 同级 `data/`；macOS release 使用 `.app` 同级 `data/`。目录不可写或 macOS AppTranslocation 明确报错，不回退系统目录，不提供改目录设置。路径解析与报错行为均未运行验证。
- **数据库适配**：Rust 创建连接池并注册到 SQL 插件 `DbInstances`；TS 使用 `Database.get()` 绑定，不调用默认 `load` 或 `close`。单连接、WAL、`synchronous=FULL`、5 秒 `busy_timeout` 只是本轮保守初值，未实测校准。
- **迁移与事务**：业务表仅落地 `entry` / `draft`，复用 SQLx 迁移机制及内部 `_sqlx_migrations` 账本，不实现自制 `PRAGMA user_version` 迁移。业务 SQL 与规则留在 TS；Rust `db_transaction` 薄命令在同一连接上提交或回滚，避免插件多次独立 `execute` 无法保证同一事务连接的问题。
- **草稿与提交**：单一 active 草稿、串行写入队列、输入法组合状态保护；输入停顿 500ms、最大等待 2000ms 只是待校准初值。提交使用固定 UUID 幂等重试，同事务新增记录并删除对应草稿；保存与退出共用提交确认，不确定结果保留 UUID 和原文，不立即清空或强制退出。
- **快捷键与错误**：Windows 默认 `Control+Shift+Space`，macOS 默认 `Super+Shift+Space`。注册失败提供可见错误与候选换键入口，不猜占用程序；换键与暂停仅本次运行生效，持久化留到阶段 2。capture 初始化错误独立保留，桌面壳启动装配失败已接入不依赖 WebView 的原生错误框（`rfd`，仅 Windows / macOS）；实际显示效果未验证。
- **未做范围**：记录浏览、编辑/删除操作、搜索、AI、完整设置、导出与备份均未实现；没有被动采集。capture 保存路径不含 AI 或网络调用，未引入 AI 发起的 entry 写入。

主要源码入口：原生装配 `src-tauri/src/main.rs`，窗口握手 `src-tauri/src/shell.rs`，便携存储 `src-tauri/src/storage.rs`，快速记录队列 `src/capture/useCapture.ts`，业务写入 `src/domains/entry.ts` / `src/domains/draft.ts`，状态页 `src/main/MainApp.vue`。

4. **高影响操作**：编译、构建、启动服务、安装/删除依赖、清理数据等，均需用户明确授权。
5. **AI 与原始记录隔离**：任何实现都不得出现由 AI 路径发起的 `entry` 写入语句。这是硬约束，不是编码风格建议。
6. **文档范围**：除用户明确要求外，不主动创建或维护模块说明文档、项目结构文档。
7. **快速记录路径纯净性**：Quick Capture 的保存路径中不得出现 AI 调用、网络请求或批量计算。
8. **用户可见内容用中文**，默认最短充分回答。

## 9. 阶段 1 必须实测的未验证项

| # | 待验证项 | 若失败的降级方案 |

| 1 | Windows 热键唤醒后能否稳定抢占前台焦点（Tauri 有 `show()` 后 `set_focus()` 失效的公开问题） | 采用 `unminimize()` → `show()` → `set_focus()` 顺序并追加一次聚焦；仍失败则评估调起时重建窗口 |
